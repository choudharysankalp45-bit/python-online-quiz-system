
# Python Online Quiz System 🎯

A simple command-line General Knowledge Quiz Application developed using Python.

## About the Project

This project is a multiple-choice quiz application containing 10 General Knowledge questions. Users can select answers from four options and receive their final score and performance evaluation.

## Features

- 10 General Knowledge questions
- Four options for each question
- Automatic answer checking
- Input validation
- Score calculation
- Percentage calculation
- Performance evaluation

## Technologies Used

- Python 3
- Visual Studio Code

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python quiz.py
```
